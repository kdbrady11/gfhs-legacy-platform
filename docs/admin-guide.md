# GFHS Legacy Alumni Platform Admin Guide

This guide explains how selected admins can manage the Great Falls High School Legacy Alumni Association website and kiosk content.

The platform is designed so content can be updated once and reused across the public website and the touchscreen kiosk experience.

---

## Admin Login

Go to:

`/admin/`

Log in with your assigned admin username and password.

Only approved association admins should have access to this area.

---

## Core Admin Responsibilities

Admins may be responsible for:

| Area | Purpose |
|---|---|
| Homepage | Update the main message, mission statement, and featured content |
| About Page | Explain the purpose and identity of the association |
| Donate Page | Explain what donations support |
| Legacy Alumni | Add, edit, and publish alumni profiles |
| School History | Add, edit, and publish historical events |
| Archives | Update archive descriptions and future archive content |
| Kiosk | Select content appropriate for public touchscreen display |

---

## Important Publishing Reminder

After making changes, always click **Publish**.

If you only click **Save Draft**, the change may not appear on the public website or kiosk.

---

## Updating the Homepage

1. Log into the admin area.
2. Go to **Pages**.
3. Select **Home**.
4. Click **Edit**.
5. Update the hero title, hero subtitle, or mission statement.
6. Click **Publish**.

The homepage introduces the purpose of the platform and explains the association’s preservation mission.

---

## Adding a Legacy Alumni Profile

1. Log into the admin area.
2. Go to **Pages**.
3. Open **Home**.
4. Open **Legacy Alumni**.
5. Click **Add child page**.
6. Choose **Alumni Detail Page**.
7. Enter the profile information.
8. Click **Publish**.

### Recommended Alumni Fields

| Field | Purpose |
|---|---|
| Title | The full display name of the alumni profile |
| First name | Used for sorting and display |
| Last name | Used for sorting and display |
| Graduation year | Class year, if known |
| Category | Legacy Alumni, Athletics, Fine Arts, Community Impact, or Faculty and Staff |
| Primary image | Main photo used across the website and kiosk |
| Short summary | Short card description |
| Biography | Longer story |
| Major achievements | Awards, accomplishments, records, or career highlights |
| Legacy statement | Why this person matters to the GFHS legacy |
| Featured on homepage | Shows the profile on the homepage |
| Featured on kiosk | Shows the profile in kiosk displays |

---

## Legacy Alumni Field Guidance

### Title

Use the person’s full name.

Example: **Jane Doe**

### First Name and Last Name

These fields are used for sorting and display.

### Graduation Year

Use the graduation year if known. Leave blank if unknown or not applicable.

### Category

Choose the best category:

- Legacy Alumni
- Athletics
- Fine Arts
- Community Impact
- Faculty and Staff

### Primary Image

Use a clear portrait or relevant historical image.

This image appears on:

- Public alumni cards
- Alumni profile pages
- Homepage featured alumni section
- Kiosk alumni cards
- Kiosk alumni detail pages

### Short Summary

Use one or two sentences. This appears on cards and kiosk displays.

Example:

> A Great Falls High School graduate recognized for a lifetime of leadership, service, and community impact.

### Biography

Use this field for the person’s longer story.

### Major Achievements

Use this field for awards, accomplishments, records, leadership roles, professional achievements, or community impact.

### Legacy Statement

Use this field to explain why the person matters to the Great Falls High School legacy.

### Featured on Homepage

Check this box if the person should appear in the homepage featured alumni section.

### Featured on Kiosk

Check this box if the person should appear in kiosk content.

## Adding a School History Event

1. Log into the admin area.
2. Go to **Pages**.
3. Open **Home**.
4. Open **History**.
5. Click **Add child page**.
6. Choose **Historical Event Page**.
7. Enter the event information.
8. Click **Publish**.

### Recommended History Fields

| Field | Purpose |
|---|---|
| Title | Name of the event or milestone |
| Event year | Year connected to the event |
| Event category | School History, Athletics, Fine Arts, Community, Building and Campus, or Tradition |
| Primary image | Main image used on public and kiosk displays |
| Short summary | Short description used on cards |
| Full story | Longer historical explanation |
| Featured on kiosk | Makes the event available for kiosk emphasis |

---

## School History Field Guidance

### Title

Use a clear title for the event or milestone.

Example: **A Tradition of Excellence**

### Event Year

Use the year connected to the event. If an exact year is unknown, use the best known year and explain the uncertainty in the story.

### Event Category

Choose the best category:

- School History
- Athletics
- Fine Arts
- Community
- Building and Campus
- Tradition

### Primary Image

Use a historical photo, school image, document scan, newspaper clipping, or relevant visual.

This image appears on:

- Public history cards
- History detail pages
- Kiosk history cards
- Kiosk history detail pages

### Short Summary

Use a concise summary of the event.

### Full Story

Use this field for the full historical explanation, including context and significance.

### Featured on Kiosk

Check this box if the event should be emphasized in kiosk displays.

## Updating the Donate Page

1. Log into the admin area.
2. Go to **Pages**.
3. Open **Home**.
4. Select **Donate**.
5. Click **Edit**.
6. Update the intro or body text.
7. Click **Publish**.

The donation page should explain what donations support, such as:

- Historical preservation
- Digitization of records
- Yearbooks and newspapers
- Kiosk displays
- Alumni recognition
- Archive maintenance

1. Log into the admin area.
2. Go to **Pages**.
3. Open **Home**.
4. Select **Archives**.
5. Click **Edit**.
6. Update the intro text.

- Yearbooks
- Newspapers
- Photos and Documents
- Athletic Records
- Programs and Events

## Kiosk Content Notes

The kiosk is web-based and uses the same content as the public website.

Current kiosk pages include:

| Kiosk Page | URL |
|---|---|
| Kiosk Home | `/kiosk/` |
| Legacy Alumni | `/kiosk/alumni/` |
| School History | `/kiosk/history/` |
| Historical Archives | `/kiosk/archives/` |

Kiosk content should be:

- Short
- Visual
- Easy to tap
- Readable from a distance
- Appropriate for public display

---

## Image Guidelines

Use images that are:

- Clear
- Historically relevant
- Approved for public use
- Appropriate for public display
- Large enough to display well

Avoid images that are:

- Blurry
- Too small
- Unapproved
- Copyright restricted
- Personally sensitive

---

## Recommended Content Review Process

Before publishing important content:

1. Confirm names are spelled correctly.
2. Confirm dates and years.
3. Confirm the person or event is categorized correctly.
4. Confirm images are approved for use.
5. Review the public page after publishing.
6. Review the kiosk page if the content appears on the kiosk.

---

## Common Troubleshooting

### I updated a page but do not see the change

Make sure you clicked **Publish**, not just **Save Draft**.

### An alumni profile does not show on the homepage

Make sure **Featured on homepage** is checked and the page is published.

### An alumni profile does not show correctly on the kiosk

Make sure **Featured on kiosk** is checked if it is intended to appear in kiosk content, and make sure the page is published.

### An image does not show

Make sure the image was selected in the **Primary image** field and the page was published after adding it.

### A page gives a 404

Make sure the page exists, has the correct slug, and has been published.
